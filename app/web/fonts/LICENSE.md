# Fonts

Self-hosted so the page looks the same everywhere and loads nothing from third parties except
ONNX Runtime Web. Latin and Latin Extended subsets (which cover Azerbaijani), taken from the
`@fontsource` npm packages.

- Source Serif 4 (variable, optical size and weight), © Adobe, SIL Open Font License 1.1
- IBM Plex Sans and IBM Plex Mono, © IBM Corp., SIL Open Font License 1.1
